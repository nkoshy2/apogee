Backups

BackupContents

Apogee backs up once a day while it's open (and catches up after days it was closed), keeps 30 days, and always keeps the newest backup. Each one holds your database, every generated resume, and checksums, and is verified before it's kept. Set a backup mirror folder above, for example an external drive or OneDrive, to keep a second copy off this disk.
